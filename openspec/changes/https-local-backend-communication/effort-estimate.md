# 工時評估（給 PM）：`https-local-backend-communication`

**評估基準：** 1 人日（PD）＝ 8 小時，含自測與基本文件，**不含**正式上線後的長尾支援工時。  
**範圍：** 對應 `tasks.md`、`specs/local-agent-https/spec.md`；假設 **agent 為現有 Python／FastAPI（或同等）堆疊**，Launcher 為本 repo 之 **Electron `main.cjs`**。

## 假設與風險（請與 PM 對齊）

| 項目 | 假設 |
|------|------|
| Agent 程式碼庫 | 與 Launcher 可分開提交；若 agent 在別 repo，需各自排程與 code review。 |
| WebSocket | 若 **目前沒有** WSS 需求，**2.2 可省略或縮小**；若已有 `ws://`，升 `wss://` 與路徑／連接埠對齊會多一段時間。 |
| 雲端 SPA | **3.2** 若在前端 monorepo／別 repo，需另排前端人力；此處以「設定／環境變數與說明」級別估算。 |
| 首次安裝種 CA（**3.5**） | macOS（鑰匙圈）與 Windows（受信任根憑證）**實作與除錯**為本 change **變動最大**區段；企業機、權限不足使用者**依規格暫不涵蓋**，但可能增加客服工時。 |
| 緩衝 | 跨團隊依賴、code review、RC 試安裝建議另加 **15–25%** 管理緩衝。 |

## 合計（建議對 PM 口徑）

| 情境 | 條件 | 合計（PD） | 合計（約略工時） |
|------|------|------------|------------------|
| **下限** | 無 WSS、CA 流程順、兩種執行型態差異小 | **約 9–10 PD** | **72–80 h** |
